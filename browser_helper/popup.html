Google Fi Data

Connect to Home Assistant

Sign in to Fi, then copy a setup code. No phone data settings are changed.

  1. Check your account in Fi

    Use a browser profile with only the Google account you want to connect.

  2. Copy your setup code

    From the signed-in Fi tab, reopen this helper and copy the code.

Then paste into the Setup code field when adding Google Fi Data in Home Assistant.
This code grants Google account access. Paste it only into your trusted Home Assistant. Clear your clipboard after setup.
